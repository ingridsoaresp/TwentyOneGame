# 🎲 Twenty-One Game

A C# Windows Forms application developed as an academic project that simulates a Twenty-One dice game.

## Overview

This desktop application allows the player to roll dice in an attempt to reach a score of 21 without going over. The game provides an interactive graphical interface built with Windows Forms and demonstrates event-driven programming, object-oriented design, and game logic.

The project was developed to practice desktop application development using C# and .NET.

---

## Features

- Windows Forms graphical interface
- Interactive gameplay
- Random dice rolls
- Running score calculation
- Win/Lose detection
- Image-based dice display
- Restart game functionality

---

## Game Rules

- Roll the dice to increase your score.
- Try to reach exactly 21.
- Going over 21 results in a loss.
- The application displays the current score after each roll.
- The player can start a new game at any time.

---

## Sample Interface

The application uses graphical dice images to display each roll and updates the score in real time.
